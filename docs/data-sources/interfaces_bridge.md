# opnsense_interfaces_bridge (Data Source)

Bridge devices (**Interfaces ▸ Devices ▸ Bridge**) join several interfaces into one layer-2 segment. Assign the resulting `device` to use it as an interface. Never bridge the interface you manage OPNsense through without console access.
