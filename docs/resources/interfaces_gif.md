# opnsense_interfaces_gif (Resource)

GIF tunnel devices (**Interfaces ▸ Devices ▸ GIF**). OPNsense names the device (`gifN`) and configures the inner addresses; assign the device to filter its traffic per interface.

## Example Usage

```terraform
resource "opnsense_interfaces_gif" "site_b" {
  local_address         = "wan"
  remote_address        = "203.0.113.20"
  tunnel_local_address  = "10.255.0.1"
  tunnel_remote_address = "10.255.0.2"
  description           = "Tunnel to site B"
}
```

## Schema

### Required

- `local_address` (String) Local outer address: an interface name such as `wan`, a CARP VIP (`wan_vip1`), an IP alias or an IP address.
- `remote_address` (String) Remote outer address.
- `tunnel_local_address` (String) Local inner address of the tunnel.
- `tunnel_remote_address` (String) Remote inner address of the tunnel.

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `device` (String) Device name, e.g. `gif0`. Assigned by OPNsense when unset.
- `disable_ingress_filter` (Boolean) Disable ingress filtering of the outer source address (`link2`). Defaults to `false`.
- `ecn_friendly` (Boolean) ECN friendly behaviour (`link1`). Defaults to `false`.
- `tunnel_remote_net` (Number) Prefix length of the inner remote address. Defaults to `32`.

### Read-Only

- `id` (String) UUID of the GIF tunnel.
