# opnsense_proxy_settings (Resource)

Settings of the Squid web proxy plugin (**Services ▸ Squid Web Proxy ▸ Administration**), including the ACLs, ICAP and authentication. Requires the `os-squid` plugin. This is a singleton: import it with the ID `proxy_settings` before managing it. Attributes left unset keep their current value.

## Example Usage

```terraform
import {
  to = opnsense_proxy_settings.this
  id = "proxy_settings"
}

resource "opnsense_proxy_settings" "this" {
  enabled              = true
  interfaces           = ["lan"]
  port                 = 3128
  acl_whitelist        = ["\\.example\\.com"]
  acl_blacklist        = ["ads\\."]
  parent_proxy_enabled = true
  parent_proxy_host    = "proxy.example.net"
  parent_proxy_port    = 8080
}
```
