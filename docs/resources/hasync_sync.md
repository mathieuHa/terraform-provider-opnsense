# opnsense_hasync_sync (Resource)

Pushes the configuration to the backup firewall and reconfigures its services, like **System ▸ High Availability ▸ Status ▸ Synchronize and reconfigure all**. The push happens when the resource is created and whenever `triggers` change; destroying the resource does nothing on the firewalls.

## Example Usage

```terraform
resource "opnsense_hasync_sync" "push" {
  triggers = {
    rules = join(",", [opnsense_firewall_filter.allow_https.id, opnsense_firewall_filter.icmp_echo.id])
  }
  depends_on = [opnsense_hasync_settings.this]
}
```
