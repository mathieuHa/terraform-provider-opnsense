# opnsense_interfaces_bridge (Resource)

Bridge devices (**Interfaces ▸ Devices ▸ Bridge**) join several interfaces into one layer-2 segment. Assign the resulting `device` to use it as an interface. Never bridge the interface you manage OPNsense through without console access.

## Example Usage

```terraform
resource "opnsense_interfaces_bridge" "lab" {
  members     = ["opt2", "opt3"]
  description = "Lab segment"
}
```

- `forward_delay` (Number) Spanning tree forward delay, in seconds. Defaults to `-1` (OPNsense default).

- `max_addresses` (Number) Size of the bridge address cache. Defaults to `-1` (OPNsense default).

- `ptp_ports` (Set of String) Members marked as point-to-point links. Defaults to `[]`.
- `span_interface` (String) Interface that receives a copy of all bridged traffic (span port).
