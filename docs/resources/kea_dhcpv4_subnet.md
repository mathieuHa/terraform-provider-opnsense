# opnsense_kea_dhcpv4_subnet (Resource)

Configure DHCPv4 subnets for Kea.

## Example Usage

```terraform
# Minimal example
resource "opnsense_kea_dhcpv4_subnet" "lan" {
  subnet      = "10.8.0.0/16"
  description = "LAN"
}

# Full resource
resource "opnsense_kea_dhcpv4_subnet" "example" {
  subnet = "10.8.0.0/16"

  next_server = "10.8.0.1"

  match_client_id = false

  auto_collect = false

  static_routes = [
    {
      destination_ip = "10.10.10.10"
      router_ip      = "10.8.0.1"
    },
    {
      destination_ip = "10.10.10.11"
      router_ip      = "10.8.50.1"
    }
  ]

  pools = [
    "10.8.2.1-10.8.2.100",
    "10.8.2.101-10.8.2.200",
    "10.8.3.0/24"
  ]

  routers = [
    "10.8.0.1",
    "10.8.50.2"
  ]

  dns_servers = [
    "10.8.0.160",
    "10.8.0.161"
  ]

  domain_name = "example.com"

  domain_search = [
    "search.example.com",
    "search2.example.com"
  ]

  ntp_servers = [
    "10.10.101.10",
    "10.10.101.11"
  ]

  time_servers = [
    "10.10.101.10",
    "10.10.101.11"
  ]

  tftp_server   = "tftp.example.com"
  tftp_bootfile = "bootfile.txt"

  description = "EXAMPLE"
}
```

## Schema

### Required

- `subnet` (String) Subnet to use (e.g. `"192.0.2.64/26"`), should be large enough to hold the specified pools and reservations.

### Optional

- `allocator` (String) Address allocator: empty for the default, `iterative`, `random` or `flq` (free lease queue). Defaults to `""`.
- `auto_collect` (Boolean) Automatically update option data from the GUI for relevant attributes. When set, values for `routers`, `dns_servers` and `ntp_servers` will be ignored. Defaults to `true`.
- `ddns_conflict_resolution_mode` (String) Conflict resolution: empty for `check-with-dhcid`, `no-check-with-dhcid`, `check-exists-with-dhcid` or `no-check-without-dhcid`. Defaults to `""`.
- `ddns_dns_port` (Number) Port of the DNS server, `-1` for 53. Defaults to `-1`.
- `ddns_dns_server` (String) Address of the DNS server that receives the updates. Defaults to `""`.
- `ddns_forward_zone` (String) Forward DNS zone updated by Kea DDNS, e.g. `lan.example.`. Requires `ddns_dns_server` and an enabled `opnsense_kea_ddns_settings`. Defaults to `""`.
- `ddns_key_algorithm` (String) TSIG algorithm: `hmac-md5`, `hmac-sha1`, `hmac-sha224`, `hmac-sha256`, `hmac-sha384` or `hmac-sha512`. Defaults to `""`.
- `ddns_key_name` (String) TSIG key name. Defaults to `""`.
- `ddns_key_secret` (String, Sensitive) TSIG key secret, base64-encoded. Defaults to `""`.
- `ddns_override_client_update` (Boolean) Update DNS even when the client wants to do it itself. Defaults to `false`.
- `ddns_override_no_update` (Boolean) Update DNS even when the client asks for no update. Defaults to `false`.
- `ddns_qualifying_suffix` (String) Suffix appended to unqualified client host names. Defaults to `""`.
- `ddns_reverse_zone` (String) Reverse DNS zone, e.g. `1.168.192.in-addr.arpa.`. Defaults to `""`.
- `ddns_update_on_renew` (Boolean) Send DNS updates on every renewal, not only for new leases. Defaults to `false`.
- `description` (String) Optional description here for your reference (not parsed).
- `dns_servers` (Set of String) DNS servers to offer to the clients. Defaults to `[]`.
- `domain_name` (String) Domain name to offer to the client, set to this firewall's domain name when left empty. Defaults to `""`.
- `domain_search` (Set of String) Set of Domain Names to be used by the client to locate not-fully-qualified domain names. Defaults to `[]`.
- `match_client_id` (Boolean) By default, KEA uses client-identifiers instead of MAC addresses to locate clients, disabling this option changes back to matching on MAC address which is used by most dhcp implementations. Defaults to `true`.
- `next_server` (String) Next server IP address. Defaults to `""`.

- `valid_lifetime` (Number) Lease lifetime in seconds for this subnet, `-1` for the server default. Defaults to `-1`.
