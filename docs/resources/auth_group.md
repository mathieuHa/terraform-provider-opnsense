# opnsense_auth_group (Resource)

Local groups (**System ▸ Access ▸ Groups**). Membership is managed on the user side with `opnsense_auth_user.group_memberships`; updating a group never changes its members.

## Example Usage

```terraform
resource "opnsense_auth_group" "readonly" {
  name       = "readonly"
  privileges = ["page-dashboard-all", "page-diagnostics-logs"]
}
```
