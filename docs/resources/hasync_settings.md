# opnsense_hasync_settings (Resource)

High availability settings (**System ▸ High Availability ▸ Settings**): CARP behaviour, pfsync state synchronisation and configuration synchronisation to a backup firewall. Configuration is pushed with `opnsense_hasync_sync` or from the GUI. This is a singleton: import it with the ID `hasync_settings` before managing it. Attributes left unset keep their current value.

## Example Usage

```terraform
import {
  to = opnsense_hasync_settings.this
  id = "hasync_settings"
}

resource "opnsense_hasync_settings" "this" {
  pfsync_interface  = "opt3"
  pfsync_peer_ip    = "10.255.255.2"
  synchronize_to_ip = "10.255.255.2"
  username          = "hasync"
  password          = var.hasync_password
  sync_items        = ["aliases", "rules", "nat", "virtualip"]
}
```

## Schema

### Optional

- `disable_preempt` (Boolean) Do not let a CARP member preempt the master role automatically.
- `disconnect_ppps` (Boolean) Disconnect PPP links when the firewall becomes CARP backup.
- `password` (String, Sensitive) Password of that user.
- `pfsync_defer` (Boolean) Defer packets until the peer acknowledges the state (pfsync defer).
- `pfsync_interface` (String) Interface used to synchronise firewall states (pfsync), e.g. `opt1`. Empty disables state synchronisation.
- `pfsync_peer_ip` (String) Unicast pfsync peer address. Empty uses multicast.
- `pfsync_version` (String) pfsync protocol version, e.g. `1400`.
- `sync_items` (Set of String) Configuration sections pushed to the backup, e.g. `["aliases", "rules", "nat"]`.
- `synchronize_to_ip` (String) Address of the backup firewall the configuration is pushed to. Empty disables configuration synchronisation.
- `username` (String) User on the backup firewall used for synchronisation.
- `verify_peer` (Boolean) Verify the TLS certificate of the backup firewall.

### Read-Only

- `id` (String) Always `hasync_settings`.
