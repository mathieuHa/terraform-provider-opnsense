# opnsense_interfaces_lagg (Resource)

Link aggregation devices (**Interfaces ▸ Devices ▸ LAGG**). Members must be unassigned physical interfaces. Never move the interface you manage OPNsense through into a LAGG without console access.

## Example Usage

```terraform
resource "opnsense_interfaces_lagg" "uplink" {
  members     = ["igb2", "igb3"]
  proto       = "lacp"
  hash        = ["l3", "l4"]
  description = "Uplink to the core switch"
}
```
