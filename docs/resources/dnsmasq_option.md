# opnsense_dnsmasq_option (Resource)

Dnsmasq DHCP options (**Services ▸ Dnsmasq DNS & DHCP ▸ DHCP options**). A `set` option is sent to clients; a `match` option tags clients that send it.

## Example Usage

```terraform
resource "opnsense_dnsmasq_option" "dns" {
  option = "6"
  value  = "192.168.1.1"
}
```

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `force` (Boolean) When enabled, the option is sent even if the client did not ask for it. Defaults to `false`.
- `interface` (String) Only send the option on this interface.
- `option` (String) DHCPv4 option number, e.g. `6` for DNS servers. Set either this or `option6`.
- `option6` (String) DHCPv6 option number, e.g. `23` for DNS servers.
- `set_tag` (String) UUID of the tag set on matching clients (type `match`).
- `tags` (Set of String) UUIDs of tags a client must carry to receive the option (type `set`). Defaults to `[]`.
- `type` (String) `set` sends the option, `match` tags clients sending it. Defaults to `set`.
- `value` (String) Option value. IPv6 addresses must be in brackets, e.g. `[2001:db8::53]`.
