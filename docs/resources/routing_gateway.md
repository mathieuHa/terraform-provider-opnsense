# opnsense_routing_gateway (Resource)

Gateways define the next hop OPNsense uses to reach other networks, and optionally how that next hop is monitored.

## Example Usage

```terraform
resource "opnsense_routing_gateway" "wan_primary" {
  name      = "WAN_PRIMARY"
  interface = "wan"
  gateway   = "203.0.113.1"

  monitor_disable = false
  monitor         = "1.1.1.1"
  latency_high    = 500
  loss_high       = 20
}

resource "opnsense_routing_gateway" "wan_backup" {
  name      = "WAN_BACKUP"
  interface = "opt1"
  gateway   = "198.51.100.1"
  priority  = 10
}
```

## Schema

### Required

- `interface` (String) Interface the gateway is reachable on, e.g. `wan` or `opt3`.
- `name` (String) Gateway name. Only `a-zA-Z0-9_-`, up to 32 characters. Routes, gateway groups and policy rules refer to the gateway by this name.

### Optional

- `data_length` (Number) Size of the ICMP probe payload in bytes. Defaults to `-1` (OPNsense default).
- `default_gateway` (Boolean) Whether this gateway is the upstream (default) gateway candidate for its address family. Defaults to `false`.
- `description` (String) Optional description here for your reference (not parsed).
- `enabled` (Boolean) Whether this gateway is enabled. Defaults to `true`.
- `far_gateway` (Boolean) When enabled, the gateway may be outside the interface subnet. Defaults to `false`.
- `force_down` (Boolean) When enabled, the gateway is marked down regardless of monitoring. Defaults to `false`.
- `gateway` (String) IP address of the gateway. Leave unset for a dynamic gateway whose address the interface learns (DHCP, PPPoE, tunnels).
- `interval` (Number) Probe interval in milliseconds. Defaults to `-1` (OPNsense default).
- `ip_protocol` (String) Address family of the gateway, one of `inet` (IPv4) or `inet6` (IPv6). Defaults to `inet`.
- `latency_high` (Number) High latency threshold in milliseconds. Defaults to `-1` (OPNsense default).
- `latency_low` (Number) Low latency threshold in milliseconds. Defaults to `-1` (OPNsense default).
- `loss_high` (Number) High packet loss threshold in percent. Defaults to `-1` (OPNsense default).
- `loss_interval` (Number) Time after which a probe without reply counts as lost, in milliseconds. Defaults to `-1` (OPNsense default).
- `loss_low` (Number) Low packet loss threshold in percent. Defaults to `-1` (OPNsense default).
- `monitor` (String) Alternative IP address to ping for monitoring. When unset, the gateway address itself is monitored.
- `monitor_disable` (Boolean) When enabled, gateway monitoring (dpinger) is disabled and the gateway is always considered up. Defaults to `true`.
- `monitor_kill_states` (Boolean) When enabled, states using this gateway are killed when it goes down. Defaults to `false`.
- `monitor_kill_states_priority` (Boolean) When enabled, states are also killed when a gateway with a higher priority comes back. Defaults to `false`.
- `monitor_no_route` (Boolean) When enabled, no static host route is added for the monitor IP. Defaults to `false`.
- `no_sync` (Boolean) When enabled, this gateway is not synchronised to an HA peer. Defaults to `false`.
- `priority` (Number) Gateway priority, lower wins when choosing the default gateway. Defaults to `255`.
- `time_period` (Number) Time period over which results are averaged, in milliseconds. Defaults to `-1` (OPNsense default).
- `weight` (Number) Weight of this gateway inside a load-balancing gateway group. Defaults to `1`.

### Read-Only

- `id` (String) UUID of the gateway.
