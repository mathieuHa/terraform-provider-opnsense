# opnsense_proxy_remote_blacklist (Resource)

Remote access control lists of the web proxy (**Services ▸ Squid Web Proxy ▸ Access Control List ▸ Remote ACLs**). The list is downloaded from `url` and denied by the proxy.

## Example Usage

```terraform
resource "opnsense_proxy_remote_blacklist" "ads" {
  filename    = "ads"
  url         = "https://lists.example.com/ads.txt"
  description = "Advertising domains"
}
```

## Schema

### Required

- `description` (String) Description of the list. Letters, digits, spaces, `.`, `,` and `_` only.
- `filename` (String) Unique local file name of the list (letters and digits, optional extension).
- `url` (String) URL the list is downloaded from.

### Optional

- `enabled` (Boolean) Whether this list is enabled. Defaults to `true`.
- `filter` (Set of String) Categories of the list to use. Empty uses all categories. Defaults to `[]`.
- `password` (String, Sensitive) Password for the download.
- `ssl_no_verify` (Boolean) Do not verify the TLS certificate of the download server. Defaults to `false`.
- `username` (String) User name for the download, if the server requires one.

### Read-Only

- `id` (String) UUID of the remote blacklist.
