# opnsense_auth_user (Resource)

Local users (**System ▸ Access ▸ Users**). API keys and OTP enrolment made outside Terraform are kept on update.

## Example Usage

```terraform
resource "opnsense_auth_user" "monitoring" {
  name               = "monitoring"
  full_name          = "Monitoring account"
  scrambled_password = true
  group_memberships  = [opnsense_auth_group.readonly.gid]
}
```

## Schema

### Required

- `name` (String) Login name.

### Optional

- `authorized_keys` (String) SSH public keys allowed for this user, one per line.
- `comment` (String) Free-form comment.
- `email` (String) Email address.
- `enabled` (Boolean) Whether the account can log in. Defaults to `true`.
- `expires` (String) Expiration date in `MM/DD/YYYY` format; leave unset for no expiry.
- `full_name` (String) Full name of the user.
- `group_memberships` (Set of String) Group IDs (`opnsense_auth_group.gid`) the user belongs to. Defaults to `[]`.
- `landing_page` (String) Page shown after login.
- `language` (String) GUI language, e.g. `en_US`; unset means the system default.
- `password` (String, Sensitive) Password. Never read back from OPNsense; leave unset to keep the current one.
- `privileges` (Set of String) Privileges granted to the user directly, on top of those of its groups. Defaults to `[]`.
- `scrambled_password` (Boolean) When enabled, OPNsense sets a random password, for accounts that only use API keys or SSH keys. The password is scrambled when the user is created with it, or when it changes from `false` to `true`; an imported user is recorded as `true`, so importing never scrambles an existing password. Defaults to `false`.
- `shell` (String) Login shell for SSH and console access; unset means no shell.
- `uid` (String) User ID assigned by OPNsense.

### Read-Only

- `id` (String) UUID of the user.
