# opnsense_routing_gateway_group (Resource)

Gateway groups combine gateways into tiers for failover and load balancing. Policy rules can use a group wherever they accept a gateway. Requires OPNsense 26.7 or later.

## Example Usage

```terraform
resource "opnsense_routing_gateway_group" "failover" {
  name    = "WAN_FAILOVER"
  trigger = "downloss"

  members = {
    (opnsense_routing_gateway.wan_primary.name) = 1
    (opnsense_routing_gateway.wan_backup.name)  = 2
  }
}
```

## Schema

### Required

- `members` (Map of Number) Gateways in the group, keyed by gateway name, with their tier (`1` to `5`) as value. Lower tiers are used first; gateways sharing a tier are load-balanced.
- `name` (String) Group name. Only `a-zA-Z0-9_-`, up to 32 characters. Policy rules refer to the group by this name.

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `pool_options` (String) Load-balancing behaviour between gateways of the same tier, one of `round-robin` or `round-robin sticky-address`. Leave unset for the OPNsense default.
- `trigger` (String) When a member is considered down, one of `down` (member down), `downloss` (packet loss), `downlatency` (high latency) or `downlosslatency` (packet loss or high latency). Defaults to `down`.

### Read-Only

- `id` (String) UUID of the gateway group.
