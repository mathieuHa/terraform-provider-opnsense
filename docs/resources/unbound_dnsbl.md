# opnsense_unbound_dnsbl (Resource)

Unbound DNS blocklist policies (**Services ▸ Unbound DNS ▸ Blocklist**). Each policy combines predefined and custom lists, and can be limited to some client networks.

## Example Usage

```terraform
resource "opnsense_unbound_dnsbl" "servers" {
  description = "Servers: ads and trackers"
  type        = ["oisd1"]
  blocklists  = ["telemetry.example.com"]
  allowlists  = ["updates.example.com"]
  source_nets = ["10.0.118.0/24", "10.0.119.0/24"]
  nxdomain    = true
}
```

## Schema

### Required

- `description` (String) Description of the policy.

### Optional

- `address` (String) Address returned for blocked names. Leave unset for `0.0.0.0` / `::`.
- `allowlists` (Set of String) Domains that are never blocked by this policy. Defaults to `[]`.
- `blocklists` (Set of String) Domains that are always blocked by this policy. Defaults to `[]`.
- `cache_ttl` (Number) How long downloaded lists are cached, in seconds. Defaults to `72000`.
- `enabled` (Boolean) Whether this policy is enabled. Defaults to `true`.
- `lists` (Set of String) URLs of additional blocklists to download. Defaults to `[]`.
- `nxdomain` (Boolean) When enabled, blocked names are answered with NXDOMAIN instead of an address. Defaults to `false`.
- `source_nets` (Set of String) Client networks this policy applies to. Empty means all clients. Defaults to `[]`.
- `type` (Set of String) Predefined blocklists by OPNsense key, e.g. `oisd1` or `hgz002`; see the GUI for the full list. Defaults to `[]`.
- `wildcards` (Set of String) Domains blocked together with all their subdomains. Defaults to `[]`.

### Read-Only

- `id` (String) UUID of the blocklist policy.
