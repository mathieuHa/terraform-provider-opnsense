# opnsense_trafficshaper_pipe (Resource)

Traffic shaper pipes limit the total bandwidth available to the traffic sent into them, either directly by a rule or through queues.

~> **Note:** like **Apply** in the GUI, changes are applied with a reload, which does not remove deleted pipes from the kernel. A deleted pipe stops receiving traffic as soon as its rules are gone, but stays visible in `ipfw pipe show` until the shaper is reset (**Firewall ▸ Shaper ▸ Reset**).

## Example Usage

```terraform
resource "opnsense_trafficshaper_pipe" "wan_upload" {
  description      = "WAN upload"
  bandwidth        = 40
  bandwidth_metric = "Mbit"
  scheduler        = "fq_codel"
}
```

## Schema

### Required

- `bandwidth` (Number) Total bandwidth of the pipe, in `bandwidth_metric` units.
- `description` (String) Description of the pipe. Queues and rules refer to the pipe by UUID, the GUI shows this text.

### Optional

- `bandwidth_metric` (String) Unit of `bandwidth`: `bit`, `Kbit`, `Mbit` or `Gbit` (per second). Defaults to `Kbit`.
- `buckets` (Number) Number of hash buckets for dynamic queues. Defaults to `-1` (OPNsense default).
- `codel_ecn_enable` (Boolean) When enabled, CoDel marks packets with ECN instead of dropping them. Defaults to `false`.
- `codel_enable` (Boolean) When enabled, CoDel active queue management is used. Cannot be combined with `pie_enable`. Defaults to `false`.
- `codel_interval` (Number) CoDel interval in milliseconds. Defaults to `-1` (OPNsense default).
- `codel_target` (Number) CoDel target queue delay in milliseconds. Defaults to `-1` (OPNsense default).
- `delay` (Number) Added delay in milliseconds. Defaults to `-1` (OPNsense default).
- `enabled` (Boolean) Whether this entry is enabled. Defaults to `true`.
- `fqcodel_flows` (Number) FQ-CoDel number of flows. Defaults to `-1` (OPNsense default).
- `fqcodel_limit` (Number) FQ-CoDel queue limit in packets. Defaults to `-1` (OPNsense default).
- `fqcodel_quantum` (Number) FQ-CoDel quantum in bytes. Defaults to `-1` (OPNsense default).
- `mask` (String) Create a dynamic queue per address: `none`, `src-ip`, `dst-ip`, `src-ip6` or `dst-ip6`. Masking by source or destination shares the bandwidth per host instead of across all traffic. Defaults to `none`.
- `pie_enable` (Boolean) When enabled, PIE active queue management is used. Cannot be combined with `codel_enable`. Defaults to `false`.
- `queue` (Number) Queue size in slots. Defaults to `-1` (OPNsense default).
- `scheduler` (String) Scheduler type: `fifo`, `rr` (deficit round robin), `qfq`, `fq_codel` (FlowQueue-CoDel) or `fq_pie` (FlowQueue-PIE). Leave unset for weighted fair queueing.

### Read-Only

- `id` (String) UUID of the pipe.
- `number` (Number) Number OPNsense assigned to the pipe (ipfw pipe number).
