# opnsense_openvpn_static_key (Resource)

OpenVPN static keys are pre-shared TLS or static keys used by OpenVPN instances for `tls-auth`, `tls-crypt`, `tls-crypt-v2` or peer-to-peer secret authentication.

## Example Usage

```terraform
variable "tls_crypt_key" {
  description = "Output of `openvpn --genkey secret`"
  type        = string
  sensitive   = true
}

resource "opnsense_openvpn_static_key" "example" {
  description = "tls-crypt key for example server"
  mode        = "crypt"
  key         = var.tls_crypt_key
}
```

## Schema

### Required

- `description` (String) Description for this static key.
- `key` (String, Sensitive) The static key payload. Use the OpenVPN-formatted key (e.g. output of `openvpn --genkey secret`).

### Optional

- `mode` (String) The static-key mode. One of `auth`, `crypt`, or `crypt-v2`. Defaults to `crypt`.

### Read-Only

- `id` (String) UUID of the static key.
