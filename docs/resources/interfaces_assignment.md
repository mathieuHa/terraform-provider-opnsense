# opnsense_interfaces_assignment (Resource)

Interface assignments (**Interfaces ▸ Assignments**) turn a device into an interface such as `opt2`, usable in firewall rules and services. OPNsense 26.7 has no API for the IP configuration of an interface, so addresses still have to be set in the GUI. Never reassign the interface you manage OPNsense through without console access.

## Example Usage

```terraform
resource "opnsense_interfaces_loopback" "services" {
  description = "Service addresses"
}

resource "opnsense_interfaces_assignment" "services" {
  device      = opnsense_interfaces_loopback.services.device
  description = "SERVICES"
}
```

## Schema

### Required

- `device` (String) Device to assign, e.g. `vtnet2`, `vlan0.10`, `lo1` or `gre0`.

### Optional

- `description` (String) Interface description, shown as its name in the GUI. Defaults to `""`.
- `lock` (Boolean) Prevent removal of the interface in the GUI. The provider unlocks the interface before deleting it. Defaults to `false`.

### Read-Only

- `id` (String) Interface identifier assigned by OPNsense, e.g. `opt2`.
