# opnsense_ipsec_pool (Resource)

Address pools for IPsec road-warrior clients (**VPN ▸ IPsec ▸ Pools**). Reference them from `opnsense_ipsec_connection.ip_pools`.

## Example Usage

```terraform
resource "opnsense_ipsec_pool" "roadwarriors" {
  name      = "roadwarriors"
  addresses = "10.10.50.0/24"
  dns       = ["10.10.0.53"]
}
```

### Required

- `addresses` (String) Network the client addresses are taken from, in CIDR notation.

- `enabled` (Boolean) Whether the pool is enabled. Defaults to `true`.
