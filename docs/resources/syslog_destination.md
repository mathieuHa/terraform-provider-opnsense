# opnsense_syslog_destination (Resource)

Remote syslog destinations (**System ▸ Settings ▸ Logging ▸ Remote**). Each destination forwards the selected programs, levels and facilities to a remote collector.

## Example Usage

```terraform
resource "opnsense_syslog_destination" "loki" {
  hostname    = "10.0.116.20"
  transport   = "tcp4"
  port        = 6514
  program     = ["filterlog"]
  rfc5424     = true
  description = "Firewall log to Loki"
}
```

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `enabled` (Boolean) Whether this destination is enabled. Defaults to `true`.

- `level` (Set of String) Severities to forward. Empty forwards all. Defaults to `[]`.
- `port` (Number) Port of the remote collector. Defaults to `514`.
- `program` (Set of String) Programs to forward, e.g. `filterlog`. Empty forwards all. Defaults to `[]`.
- `rfc5424` (Boolean) When enabled, messages are sent in RFC 5424 format instead of the BSD format. Defaults to `false`.
- `transport` (String) Transport protocol and address family. Defaults to `udp4`.

- `id` (String) UUID of the syslog destination.
