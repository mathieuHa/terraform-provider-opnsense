# opnsense_interfaces_vxlan (Resource)

VXLAN devices (**Interfaces ▸ Devices ▸ VXLAN**). The device is `vxlan<device_id>`; set either `remote` (unicast) or `group` (multicast).

## Example Usage

```terraform
resource "opnsense_interfaces_vxlan" "dc" {
  vni    = 100
  local  = "192.0.2.10"
  remote = "192.0.2.20"
}
```

## Schema

### Required

- `local` (String) Local address the VXLAN traffic is sent from.
- `vni` (Number) VXLAN network identifier.

### Optional

- `device_id` (Number) Number of the device (`vxlan<device_id>`). Assigned by OPNsense when unset.
- `group` (String) Multicast group address.
- `interface` (String) Interface used for multicast, e.g. `wan`.
- `local_port` (Number) Local UDP port. Defaults to `-1` (OPNsense default).
- `remote` (String) Unicast remote address.
- `remote_port` (Number) Remote UDP port. Defaults to `-1` (OPNsense default).

### Read-Only

- `device` (String) Device name, `vxlan<device_id>`.
- `id` (String) UUID of the VXLAN.
