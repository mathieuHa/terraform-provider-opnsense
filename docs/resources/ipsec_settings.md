# opnsense_ipsec_settings (Resource)

Global IPsec settings (**VPN ▸ IPsec ▸ Advanced Settings**) and the IPsec on/off switch. This is a singleton: import it with the ID `ipsec_settings` before managing it. Attributes left unset keep their current value.

## Example Usage

```terraform
import {
  to = opnsense_ipsec_settings.this
  id = "ipsec_settings"
}

resource "opnsense_ipsec_settings" "this" {
  enabled              = true
  make_before_break    = true
  passthrough_networks = ["192.168.1.0/24"]
}
```

### Optional

- `cisco_unity` (Boolean) Send the Cisco Unity vendor ID payload (IKEv1 only).
- `disable_vpn_rules` (Boolean) Do not add the automatic firewall rules for IPsec.
- `enabled` (Boolean) Whether IPsec is enabled (**VPN ▸ IPsec ▸ Connections ▸ Enable IPsec**). Leave unset to keep the current value.
- `ignore_acquire_ts` (Boolean) Ignore the traffic selectors from the kernel's acquire events.
- `ikesa_table_segments` (Number) Number of exclusively locked segments in the IKE SA hash table.
- `ikesa_table_size` (Number) Size of the IKE SA hash table.
- `init_limit_half_open` (Number) Limit of half-open IKE SAs before new initiation requests are dropped.
- `install_routes` (Boolean) Let charon install routes into a separate routing table for established IPsec tunnels.
- `make_before_break` (Boolean) Initiate IKEv2 reauthentication with a make-before-break instead of a break-before-make scheme.
- `max_ikev1_exchanges` (Number) Maximum number of IKEv1 phase 2 exchanges per IKE SA.
- `passthrough_networks` (Set of String) Networks excluded from IPsec processing, e.g. local networks covered by a wider tunnel.
- `preferred_oldsa` (Boolean) Prefer older SAs over newer ones.
- `reqid_base` (Number) First reqid to assign automatically to children.
- `retransmit_base` (String) Base of the exponential backoff for retransmits.
- `retransmit_jitter` (Number) Maximum jitter in percent applied randomly to calculated retransmission timeouts.
- `retransmit_limit` (Number) Upper limit in seconds for the calculated retransmission timeout.
- `retransmit_timeout` (String) Timeout in seconds before sending the first retransmit.
- `retransmit_tries` (Number) Number of times to retransmit a packet before giving up.
- `threads` (Number) Number of worker threads in charon.

### Read-Only

- `id` (String) Always `ipsec_settings`.
