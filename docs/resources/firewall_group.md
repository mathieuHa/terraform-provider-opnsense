# opnsense_firewall_group (Resource)

Interface groups combine interfaces so firewall rules can be written once for all of them. Each group also gets its own tab under **Firewall ▸ Rules**.

## Example Usage

```terraform
resource "opnsense_firewall_group" "servers" {
  name        = "servers"
  members     = ["opt1", "opt2", "opt3"]
  description = "All server networks"
}
```

## Schema

### Required

- `members` (Set of String) Interfaces in the group, e.g. `["lan", "opt1"]`.
- `name` (String) Group name, used as the interface name in rules. At most 15 characters and must not end with a digit.

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `no_group` (Boolean) When enabled, the group is hidden from the interface list of the rules menu. Defaults to `false`.
- `sequence` (Number) Position of the group in the rules menu. Defaults to `0`.

### Read-Only

- `id` (String) UUID of the interface group.
