# opnsense_dnsmasq_boot (Resource)

Dnsmasq network boot entries (**Services ▸ Dnsmasq DNS & DHCP ▸ DHCP boot**) point PXE clients at a boot file and TFTP server.

## Example Usage

```terraform
resource "opnsense_dnsmasq_boot" "pxe" {
  tags           = [opnsense_dnsmasq_tag.pxe.id]
  filename       = "ipxe.efi"
  server_address = "192.168.1.10"
}
```
