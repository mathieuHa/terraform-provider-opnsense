# opnsense_core_tunable (Resource)

System tunables set kernel `sysctl` values and boot-time loader variables (**System ▸ Settings ▸ Tunables**). Loader variables only take effect after a reboot.

## Example Usage

```terraform
resource "opnsense_core_tunable" "delayed_ack" {
  tunable = "net.inet.tcp.delayed_ack"
  value   = "0"
}
```
