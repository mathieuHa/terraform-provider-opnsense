# opnsense_trafficshaper_rule (Resource)

Traffic shaper rules select traffic and send it to a pipe or a queue.

## Example Usage

```terraform
resource "opnsense_trafficshaper_rule" "voip_out" {
  description = "VoIP upload"
  sequence    = 10
  interface   = "wan"
  direction   = "out"
  protocol    = "udp"
  dscp        = ["ef"]
  target      = opnsense_trafficshaper_queue.voip.id
}

resource "opnsense_trafficshaper_rule" "everything_else_out" {
  description = "Everything else upload"
  sequence    = 100
  interface   = "wan"
  direction   = "out"
  target      = opnsense_trafficshaper_queue.bulk.id
}
```

### Required

- `interface` (String) Interface the rule matches on, e.g. `wan`.
- `target` (String) UUID of the pipe or queue matching traffic is sent to.

### Optional

- `description` (String) Optional description here for your reference (not parsed).
- `destination` (Set of String) Destination networks or addresses to match, or `any`. Defaults to `["any"]`.
- `destination_not` (Boolean) When enabled, the destination match is inverted. Defaults to `false`.
- `destination_port` (String) Destination port to match. A port, a range (`8000-8080`), a well-known name or `any`. Defaults to `any`.
- `direction` (String) Traffic direction relative to `interface`: `in` or `out`. Leave unset to match both.
- `dscp` (Set of String) DSCP values to match, e.g. `ef` or `af41`. Defaults to `[]` (any).
- `enabled` (Boolean) Whether this entry is enabled. Defaults to `true`.
- `interface2` (String) Second interface, to only match traffic flowing between `interface` and this one.
- `ip_length` (Number) Only match packets up to this size in bytes, e.g. small ACKs. Defaults to `-1` (OPNsense default).
- `protocol` (String) Protocol to match: `ip`, `ip4`, `ip6`, `udp`, `tcp`, `tcp_ack`, `tcp_ack_not`, `icmp`, `ipv6-icmp`, `igmp`, `esp`, `ah` or `gre`. Defaults to `ip`.
- `sequence` (Number) Order in which rules are evaluated, lowest first; the first match wins. Defaults to `1`.
- `source` (Set of String) Source networks or addresses to match, or `any`. Defaults to `["any"]`.
- `source_not` (Boolean) When enabled, the source match is inverted. Defaults to `false`.
- `source_port` (String) Source port to match. A port, a range (`8000-8080`), a well-known name or `any`. Defaults to `any`.
